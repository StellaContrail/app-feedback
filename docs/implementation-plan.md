# 実装計画

## マイルストーン1 — ページ要素へのコメント共有

対象は pnpm モノレポ（`apps/api`、`apps/extension`、`packages/shared`）、Hono / D1、Chrome MV3 拡張機能です。全パッケージで TypeScript strict を有効にし、Zod で入力を検証します。AI、スクリーンショット、R2、管理画面は含めません。

Google ログイン後、任意の HTTP(S) サイトをオリジン単位で共有し、正規化ルートでコメントを分離します。招待・固定の遷移先・イベント期限は使用しません。旧プライベートデータは別に保持し、自動公開しません。認証・データ形式は [API 契約](api-contract.md)を参照してください。

ユーザー操作による activeTab + scripting で UI を挿入し、Shadow DOM でページから分離します。要素の選択時は本来のクリック動作を抑止し、Escape で選択を終了します。ピンの対象を安全に解決できない場合は一覧に残します。SPA 遷移・DOM 変更・二重挿入・削除時の後処理を検証対象とします。

### 受入基準

- A がボタンを選択して投稿し、別プロファイルの B が同じページを再読み込みしてピンを確認できること。
- 別のオリジン・ルート、旧プライベートセッションからコメントが混入しないこと。
- 選択で遷移・フォーム送信が起きず、ページ CSS が UI に影響しないこと。
- 全サイト権限を要求せず、DOM 全体・フォーム値・Cookie を永続化しないこと。
- 期限切れ・旧参加者・招待・管理者トークンでサイト共有を認可できないこと。
- lint・型チェック・単体/DOM テスト・Workers 内の実 D1 統合テストが成功すること。

自動テストだけでは実アカウントの Google 同意と人によるツールバー操作・目視確認を完了としません。[手動受入手順](manual-test.md)で確認します。

## 後続マイルストーン

- **マイルストーン2**: レビュー管理、有効期限・削除、JSON/CSV エクスポート。現状はログイン済みの全ユーザーでサイトを共有するため、サイト所有権・モデレーション・非公開グループには別途認可設計が必要です。
- **マイルストーン3**: 明示的な同意による表示領域のスクリーンショット、アップロード前のプレビュー・マスキング、非公開 R2 とアクセス制御、MIME・サイズ検証、Playwright E2E。スクリーンショットは明示的な承認まで着手しません。

サイトレビューの GitHub Issues への自動転送、AI 修正、ソースマッピング、モバイル、匿名コメント、制限のない匿名アクセス、トラッキングは対象外です。拡張機能自体へのフィードバックは、ユーザーが GitHub 上で確認・送信する別の導線です。
